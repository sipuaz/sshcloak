# Security Policy

## Supported versions

The latest tagged release and the current `main` branch are supported.

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.

Use GitHub's private vulnerability reporting flow instead:

1. Open the repository on GitHub.
2. Go to **Security**.
3. Choose **Report a vulnerability**.
4. Provide a clear description, reproduction steps, and any relevant proof of concept.

If GitHub private vulnerability reporting is unavailable for this repository,
open a private communication channel with the maintainer before disclosing the
issue publicly.

## What to include

A useful report should include:

- The affected version or commit
- The impact and attack scenario
- Reproduction steps
- Any suggested fix or mitigation
